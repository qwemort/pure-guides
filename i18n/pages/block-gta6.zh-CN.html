如何在 YouTube、Reddit 和 X 上屏蔽 GTA 6 剧透

更新于 2026-11-14

简短回答。YouTube 和 Reddit 没有屏蔽关键词的功能，所以缩略图、标题和评论里的 GTA VI 剧透都会漏进来。真正有用的是浏览器扩展：读取页面内容，把匹配的视频、帖子和评论模糊掉。我做了一个，叫 Pure Spoiler Blocker：免费，自带现成的 GTA VI 列表，完全在本地运行。

免费把 Pure Spoiler Blocker 添加到 Chrome
说明：这个扩展是我做的。也有 Firefox 版。

在这里直接试试

一个虚构的 YouTube 风格信息流，没有真正的剧透。打开 Shield，看 GTA VI 剧透视频被模糊，预告片和其他内容照常显示（这是“仅剧透”级别）。

GTA VI 列表会隐藏什么

  • 标题的 22 种写法（拉丁字母、西里尔字母、日文/中文、韩文）。默认隐藏剧透类讨论（结局、泄露、反转之类），普通新闻和预告片保留。把级别调到“全部”就能全部隐藏。
  • 列表里的 47 个角色名和地名。只属于 GTA VI 的名字单独出现也会被识别。和普通词语重名的名字，只在本来就和 GTA VI 有关的页面上才算数。
  • 适用于 YouTube（首页、搜索、Shorts、评论）、Reddit（帖子和评论）和 X。
  • 想看被隐藏的内容，点两下即可。什么都不会删除，只是盖住。

坦白说明局限：它读取的是文字，所以只存在于缩略图图片里、没有文字的剧透可能会漏过。它在电脑浏览器里运行，不支持手机 App。

一分钟设置好

  1. 从 Chrome 应用商店安装 Pure Spoiler Blocker。
  2. 打开扩展，在现成作品列表里开启 GTA VI。
  3. 打开 YouTube 或 Reddit。匹配的卡片和评论会立刻被模糊。

不装扩展时各网站能做什么

  • X：屏蔽关键词。可直接复制的列表：GTA VI 屏蔽词列表EN。
  • Threads：设置、隐私、隐藏字词。
  • YouTube：“不感兴趣”和“不推荐此频道”，只能逐个视频操作。
  • Reddit：只能屏蔽整个社区，不能屏蔽词语。

常见问题

YouTube 自己能屏蔽 GTA VI 剧透吗？

不能。YouTube 没有关键词过滤。你可以在单个视频上点“不感兴趣”或“不推荐此频道”，但新的剧透缩略图、Shorts 和评论还是会出现。

怎么在 Reddit 上隐藏 GTA VI 剧透？

Reddit 只能屏蔽整个社区，不能屏蔽词语，所以其他子版块和搜索里关于 GTA VI 的帖子依然会出现。想按词语过滤，只能用读取帖子标题和评论的扩展。

X（Twitter）有 GTA VI 剧透过滤吗？

有，X 可以屏蔽关键词。它会隐藏包含这些词的帖子，但管不到 YouTube 上的同类视频和 Reddit 上的帖子。

Pure Spoiler Blocker 免费吗？

是的，全部免费。现成的 GTA VI 列表、其他现成列表，以及任意数量的自定义作品，都能在 YouTube、Reddit 和 X 上使用，点一下还能用于 Google 搜索、TikTok 和 Instagram。没有付费版，也不需要账号。

它会收集我的数据吗？

不会。它在你的浏览器里运行，不需要账号，不做追踪，源代码公开。
