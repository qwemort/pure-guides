# Очередь постов в Threads

Файл `ГГГГ-ММ-ДД.json` (дата по UTC) = пост на этот день: `{"threads": "текст", "image": "https://qwemort.github.io/pure-guides/media/queue/ГГГГ-ММ-ДД.png"}`. Картинка лежит в `media/queue/`.
Workflow `scheduled-post` каждое утро (~04:20 UTC, GitHub часто опаздывает) публикует файл за сегодня в Threads и пишет `posted-ДАТА.txt`, чтобы не выложить дважды. Не хочешь постить — удали файл до утра.
Только свои картинки без личных данных: репозиторий публичный.
